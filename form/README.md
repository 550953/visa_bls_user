# Анкета заявителя (мобильная)

Пошаговая HTML-форма для заполнения 61 поля визовой анкеты на смартфоне.

## Файлы

```
app/
├── index.html   — хаб: список 9 разделов + прогресс + JSON
├── form.html    — экран одного раздела (?g=g1 … g9)
├── style.css    — мобильные стили
├── app.js       — конфиг полей, localStorage, валидация
└── README.md
```

## Как открыть

1. Открой `index.html` в браузере (на телефоне или в DevTools → mobile).
2. Тап по разделу → `form.html?g=g1` и т.д.
3. «Сохранить и назад» пишет данные в `localStorage` и возвращает на хаб.
4. «Сформировать JSON» — валидация и выдача итогового JSON (61 поле).

## Разделы

| ID  | Название                  | Полей |
|-----|---------------------------|-------|
| g1  | Личные данные             | 11    |
| g2  | Паспорт                   | 8     |
| g3  | Адрес и контакты          | 6     |
| g4  | Работодатель              | 4     |
| g5  | Поездка                   | 9     |
| g6  | Принимающая сторона       | 7     |
| g7  | Контакт (принимающей)     | 8     |
| g8  | Финансы                   | 2     |
| g9  | Родственник (ЕС/ЕЭЗ)      | 6 (опционально) |

## Данные

- Автосохранение в `localStorage` (ключ `schengen_form_mobile_v1`).
- Меню «⋯» → скачать / загрузить черновик (JSON-файл).
- Итоговый JSON: ключи в порядке 1–61, даты `ГГГГ-ММ-ДД`.

## Telegram WebApp

Бот может открыть `index.html` как WebApp. Данные лежат в `localStorage`; при необходимости можно добавить `postMessage` / `Telegram.WebApp.sendData`.
